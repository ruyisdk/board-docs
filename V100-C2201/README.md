# SpacemiT V100-C2201

The SpacemiT V100-C2201 is a 2U dual-socket rackmount server based on the SpacemiT V100 RISC-V processor, which combines SpacemiT X100 and XiangShan Kunminghu V2R2 cores. The platform provides 16 DDR5 RDIMM slots supporting up to 2 TB of memory, PCIe 5.0 expansion, and NVMe and SATA storage. An integrated AST2600 BMC provides remote management alongside standard UEFI and ACPI firmware. The server is designed for data centers, cloud computing, scientific computing, and general-purpose server workloads.

For product specifications, see the [official C2201 product page](https://www.spacemit.com/community/development-kit/v100-c2201).
