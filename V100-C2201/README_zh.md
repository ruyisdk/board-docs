# SpacemiT V100-C2201

SpacemiT V100-C2201 是一款基于 SpacemiT V100 RISC-V 处理器的 2U 双路机架式服务器，处理器采用 SpacemiT X100 与香山昆明湖 V2R2 核心的混合架构。平台提供 16 个 DDR5 RDIMM 插槽，最高支持 2 TB 内存，并支持 PCIe 5.0 扩展及 NVMe、SATA 存储。服务器采用标准 UEFI 和 ACPI 固件，集成 AST2600 BMC 以提供远程管理能力，适用于数据中心、云计算、科学计算及通用服务器应用。

产品规格详见 [C2201 官方产品页面](https://www.spacemit.com/community/development-kit/v100-c2201)。
