# HiFive Premier P550

## 概述

HiFive Premier P550 是一款基于 ESWIN EIC7700X SoC 的高性能 RISC-V 开发板。EIC7700X 搭载四核 SiFive Performance P550 64 位乱序执行处理器，主频为 1.4 GHz，并集成 GPU、视频编解码器和 AI NPU。

该开发板提供 16GB 或 32GB LPDDR5 内存和 128GB eMMC 存储，配备 PCIe Gen 3、双千兆以太网、USB 3.2、SATA 3、HDMI 2.0、microSD 卡槽和 40 针扩展接口，并预装 Ubuntu 24.04，适用于高性能 RISC-V Linux 软件开发。
