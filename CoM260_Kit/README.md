# CoM260 Kit

The CoM260 Kit is a compact RISC-V development kit based on the SpacemiT K3 SoC. It integrates eight X100 general-purpose cores and eight A100 AI cores, and is available with 8 GB, 16 GB, or 32 GB of LPDDR5 memory. The board provides UFS storage, NVMe expansion, Gigabit Ethernet, Wi-Fi 6, Bluetooth 5.0, display, camera, and industrial expansion interfaces for edge AI and embedded application development.
