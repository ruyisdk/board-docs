# 模板概述

这里提供了针对不同开发板和示例的报告模板，旨在帮助贡献者记录和分享他们的测试结果。每个模板都包含了必要的结构和格式，以确保信息的清晰和一致性。

## 使用说明

1. **针对开发板的文档模板**：`templates/[board-name]/README.md` 为英文模板，`templates/[board-name]/README_zh.md` 为中文模板，用于记录特定开发板的基本信息、硬件规格。

2. **针对示例的文档模板**：`templates/[board-name]/[example-name]/README_zh.md` 为中文模板，英文模板 `templates/[board-name]/[example-name]/README.md` 为可选内容，用于记录特定示例的编译运行环境、运行步骤、实际结果。

请根据具体的开发板和示例，填充和修改相应的模板内容。
